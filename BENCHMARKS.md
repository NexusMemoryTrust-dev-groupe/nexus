## Зачем этот документ

Маркетинг говорит «экономит до 80%». Плохой маркетинг говорит это без доказательств.

Nexus публикует **измерения реального движка**:

- **1320 реальных файлов** из открытых проектов (requests, rust-log, Material-UI) проиндексированы реальной ONNX-моделью `all-MiniLM-L6-v2` (384-мерные эмбеддинги);
- **118 наводящих вопросов** прогнаны через реальный пайплайн сборки контекста — от затравки до ранжирования и сжатия;
- **Токены считает реальный tiktoken gpt-4o** (офлайн, точно), а не эвристика «символы / 4»;
- **Безопасность** проверена реальными атакующими нагрузками (path traversal, секреты, prompt injection, права агентов) против реальных путей кода;
- Полный воспроизводимый отчёт — [NEXUS_BENCHMARK_REPORT.md](NEXUS_BENCHMARK_REPORT.md), харнессы — в `src-tauri/src/bin/`.

## 2. Retrieval — поиск реванширует над ключевыми словами

Вопрос «где живёт ответ» — самый честный тест памяти. Мы знаем, в каком файле по определению лежит ответ, и проверяем, найдёт ли его Nexus.

| Стратегия | P@5 | R@5 | R@20 |
|:---|:---:|:---:|:---:|
| Ключевые слова (наивное совпадение терминов) | 0.08 | 0.30 | 0.50 |
| **Nexus hybrid (семантика + граф)** | **0.23** | **0.95** | **0.97** |

**Преимущество hybrid × дальше растёт с размером корпуса:**

| Датасет | Запросов | R@5 | R@20 | MRR@10 | NDCG@10 |
|:---|:---:|:---:|:---:|:---:|:---:|
| requests (Python, 130 файлов) | 25 | 0.77 | 0.81 | 0.96 | 0.81 |
| rust-log (Rust, 23 файла) | 13 | 0.86 | 0.94 | 0.86 | 0.83 |
| **Material-UI (JS/TS, ~1230 файлов)** | **80** | **0.99** | **1.00** | **0.97** | **0.98** |

> На однородном корпусе из >1000 файлов наивный поиск «тонет» — а гибридный движок Nexus удерживает почти идеальный recall. И это debug-сборка: release-бинарник и горячий кэш эмбеддингов работают кратно быстрее.

## 3. Контекстный пайплайн — до 94% экономии токенов

Ядро Nexus: вместо горы сырых файлов модели отдаётся плотный, ранжированный пакет. Цифры — реальное сжатие (tiktoken gpt-4o, baseline «до» сжатия).

| Мера | До | После |
|:---|:---:|:---:|
| Средние токены на запрос | ~17 000 | ~1 000 |
| **Сокращение** | — | **94.2%** |
| Латентность сборки (debug, без прогрева) | 5 640 ms | **1 863 ms** |
| Чанкинг длинных файлов (1024 B / overlap 128) | — | missing rate 0.0000 |

**Метод честный по построению:**
1. Baseline считается **до** сжатия — это сырой объём данных;
2. Результат считается **после** — токенизатором целевой модели (tiktoken, BPE из embedding-модели);
3. Поле `token_method` говорит `exact` или `estimated` — оценка никогда не выдаётся за точность.

## 4. Безопасность — 55 из 55 атак отражены

Каждый тест — реальная нагрузка против реального кода (`core::sandbox`, `security`, `memory_firewall`, `agent_permissions`, MCP-диспетчер, SQLite). Ноль моков.

| Слой защиты | Что атаковали | Результат |
|:---|:---|:---:|
| **Песочница путей** | traversal `..`, абсолютные пути вне корня, `CON/NUL/COM1`, URL-encoded обход, sibling-prefix | **10/10** |
| **Секреты** | JWT по форме, `sk-` ключи, PEM-блоки, `password=` — детекция и редактирование | **19/19** |
| **Prompt injection** | payload остаётся данными, секрет внутри — редактируется | **23/23** |
| **Файрвол памяти** | токсичность, инъекции, user-правила Block/Quarantine | **30/30** |
| **Права агентов** | deny-паттерны, видимость Private, слои Decision, отключённая политика = Deny | **37/37** |
| **RequestContext** | deny-by-default, чувствительность Restricted, write-права | **45/45** |
| **MCP-поверхность** | неизвестные инструменты, битый JSON, oversized payload | **52/52** |
| **Повреждённая БД** | мусорный файл, каталог как БД, усечённый заголовок | **55/55** |

| Итог | Значение |
|:---|:---:|
| **Все категории** | **55/55 — 100.0%** |

**Живые примеры из логов теста:**


## 6. Тривиальный вопрос: а кому это нужно? Nexus vs Obsidian vs Notion

Obsidian и Notion — прекрасные **инструменты заметок**. Nexus — **операционная система памяти для ИИ**. Это разные классы продуктов: заметочник хранит текст, Nexus кормит ассистента плотным контекстом и объясняет, почему выбрал именно его.

| Критерий | Nexus | Obsidian | Notion |
|:---|:---:|:---:|:---:|
| Постоянная память для ИИ-агентов | Полностью | Нет | Нет |
| Провенанс: видно, **почему** фрагмент попал в контекст | Да | Нет | Нет |
| Семантический поиск по эмбеддингам (локальный ONNX) | Да | Плагин, внешний API | Нет |
| Сборка контекста под бюджет токенов для LLM | Да | Нет | Нет |
| 143 MCP-инструмента для любого ИИ | Да | Нет | Нет |
| Граф знаний сущностей + связей | Да | Да (плагин) | Частично |
| 3D-визуализация графа с LOD | Да | Нет | Нет |
| Жизненный цикл памяти: конфликты, устаревание, подтверждение | Да | Нет | Нет |
| Когнитивные слои (Working → Strategic) | Да | Нет | Нет |
| Каноническая консолидация (дистилляция дублей) | Да | Нет | Нет |
| Rights агентов: deny-by-default, категории, слои | Да | Нет | Нет |
| Файловая песочница для ИИ-инструментов | Да | Нет | Нет |
| Данные только на вашем диске, без облака | Да | Частично (vault локальный) | Нет (облако) |
| Работает без интернета | Да (кроме вызовов ИИ) | Да | Нет |
| Бесплатно, с бесплатными ИИ-моделями | Да | Да | Частично |
| API для собственных агентов | Да (MCP + Node.js SDK) | Нет | Нет |
| Аудит: append-only журнал всех действий | Да | Нет | Нет |

**Короткая версия:** Obsidian запоминает для *человека*, Notion — для *организации*, Nexus — для *искусственного интеллекта*. Разница — не в функциях заметок, а в том, что Nexus делает память агента **живой, объяснимой и безопасной**.

Хотите проверить сами? Nexus бесплатен:

| Способ | Команда |
|:---|:---|
| Установщик Windows | [Скачать последнюю версию](https://github.com/NexusMemoryTrust-dev-groupe/nexus/releases/latest) |

| PowerShell | `irm https://raw.githubusercontent.com/NexusMemoryTrust-dev-groupe/nexus/master/npm-package/scripts/install-nexus.ps1 \| iex` |

**Воспроизвести бенчмарк локально:**

```powershell
cd src-tauri
cargo build --bin nexus_bench
$env:NEXUS_BENCH_FASTEMBED_CACHE = "$env:LOCALAPPDATA\Nexus\.fastembed_cache"
.\target\debug\nexus_bench.exe --projects "$env:TEMP\opencode\nexus-bench\projects"
```
